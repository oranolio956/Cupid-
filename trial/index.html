3. Load the extension in Chrome

Enable developer mode, then point Chrome at the unpacked folder.

  1. Open Chrome → click the puzzle icon → Manage Extensions (or use the shortcut below).
  2. Toggle Developer mode in the top-right corner.
  3. Select Load unpacked and choose the cupidbotofm_0.19.151 folder you just extracted.
  • Use ⌘ + Space → type “Extensions” to jump directly, or open chrome://extensions.
  • Toggle the Developer mode switch in the top-right corner.
  • Click Load unpacked → select the extracted cupidbotofm_0.19.151 folder from Finder.
  • Confirm the permission prompt so Chrome whitelists the workspace bundle.
  • Press Ctrl + L and type chrome://extensions, or use the puzzle icon → “Manage Extensions”.
  • Enable Developer mode using the toggle in the top-right corner of the page.
  • Click Load unpacked → choose the extracted cupidbotofm_0.19.151 folder from File Explorer.
  • Approve the verification prompt so Chrome trusts the CupidBot bundle.
Heads up

Chrome may prompt you to confirm loading the folder. Approve it—this is the signed production build we ship to operators. Chrome security does not allow unattended installs, so every seat must click “Load unpacked” the first time.

Didn’t see the Chrome popup?

Make sure the chrome://extensions tab is foregrounded and developer mode is toggled on. If nothing happens after clicking “Load unpacked”, refresh the tab and try again—or drag the cupidbotofm_0.19.151 folder directly into the extensions page.

We’ll try to launch chrome://extensions in a new tab. If Chrome blocks it, copy the link into your address bar manually.
