1. Confirm your setup

Match the environment our OFM operators use before loading the extension.

  • Chrome desktop on macOS or Windows, signed into the profile tied to your OFM seat.
  • Version 114 or later with automatic updates enabled.
  • Local admin access so you can manage extensions.

Chrome opens chrome://settings/help in a new tab to confirm your version.

2. Download CupidBot OFM

We distribute the workspace as a signed package so you can bypass the public Chrome Web Store.

  • Unzip the download to reveal the cupidbot-extension folder.

3. Load the extension in Chrome

Enable developer mode, then point Chrome at the unpacked folder.

  1. Open Chrome → click the puzzle icon → Manage Extensions (or use the shortcut below).
  2. Toggle Developer mode in the top-right corner.
  3. Select Load unpacked and choose the cupidbot-extension folder you just extracted.
  • Use ⌘ + Space → type “Extensions” to jump directly, or open chrome://extensions.

Heads up

Chrome may prompt you to confirm loading the folder. Approve it—this is the signed production build we ship to operators. Chrome security does not allow unattended installs, so every seat must click “Load unpacked” the first time.

4. Finish & verify

Lock in the install so your operators can start session work immediately.

  • Pin the CupidBot icon from the extensions tray for quick access.
  • Open the popup and sign in with your OFM workspace credentials.
  • Enter the workspace token from ops to sync scripts and routing.
