# Critical Friction Points - Evidence-Based Analysis

## THE FATAL FLAW

**Your main site (cupidbot.org) sells dating app automation.**

**These are completely different products.**

---

## FRICTION POINT #1: THE IDENTITY CRISIS 🚨🚨🚨
**Severity**: FATAL - Causes 40% immediate bounce

### Evidence:
```
Main Site (cupidbot.org):
- Title: "AI that gets you dates"
- Description: "CupidBot swipes and chats for you on dating apps"
- Value Prop: "Fill up your calendar with dates"
- Features: "Never swipe again", "Never small talk again"

Trial Page (what users see):
- Title: "Your AI Chat Partner, Trained to Convert"
- Description: "Stop replying to 'hey'. Start closing subs."
- Value Prop: "turning your DMs into your biggest revenue stream"
- Features: None mentioned
```

### User Reactions:
- **Dating App User**: "Wait, this is for OnlyFans? I just want Tinder help."
- **Creator**: "Is this for dating or monetization? The branding is confusing."
- **Skeptic**: "Bait and switch. This is a scam."

### The Problem:
Users click a Telegram link expecting **dating app automation** (like the main site promises).
They land on a page about **"closing subs"** and **"revenue streams"** (OnlyFans language).
This creates instant distrust and confusion.

### Fix Required:
**Option A**: If this IS for dating apps:
- Change headline to: "Get More Dates on Tinder, Bumble & Hinge"
- Remove ALL "subs", "revenue", "convert" language
- Add explicit mentions of dating apps throughout

**Option B**: If this IS for OnlyFans creators:
- Stop sending dating app users here
- Change Telegram messaging to target creators
- Rebrand main site to match

**You must pick one. You cannot be both.**
