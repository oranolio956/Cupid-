Chrome install guide

1. Confirm your setup

Ensure your environment matches what our operators use in production.

  • Chrome desktop on macOS or Windows (profiles linked to your OFM seat).
  • Browser version 114 or later with automatic updates enabled.
  • Local admin access to install and manage extensions.

Chrome will launch chrome://settings/help in a new tab to confirm your version.

2. Download CupidBot OFM

We distribute the extension as a signed package so you can deploy without waiting on the Chrome Web Store.

ZIP package Version 1.0.0 Updated Nov 2025

cupidbot-ofm-extension.zip

Includes the unpacked extension folder, assets, and manifest. Keep the folder in a secure drive your operators can access.

Download package
  • After downloading, unzip the file to reveal the cupidbot-extension folder.
  • Store the folder where it will not be moved (Desktop or Applications is perfect).

3. Load the extension in Chrome

Enable developer mode, then point Chrome at the unpacked folder.

  1. Open Chrome → click the puzzle icon → Manage Extensions (or use the shortcut below).
  2. Toggle Developer mode in the top-right corner.
  3. Choose Load unpacked and select the unzipped cupidbot-extension folder.
Heads up

Chrome may prompt you to confirm loading the folder. Approve it—this is our signed production build.

4. Finish & verify

Lock in the install so your operators can start session work immediately.

  • Pin the CupidBot icon from the extensions tray for fast access.
  • Open the popup and sign in with your OFM workspace credentials.
  • Enter the workspace token provided by ops to sync scripts and routing.
✓ Install verified

Your Chrome seat is ready. Keep the extracted folder untouched; future updates will replace it. For additional seats, repeat this guide.
